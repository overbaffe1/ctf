# Решение CTF: BrandGuard CDN

## Флаги

1. **Обмен (exchange.wasm + capture.json)** — `flag{lagged_limb_9d2f31}`
2. **«Секста» (sexta.dat)** — `flag{unaligned_watch_81d4}`

## 1. Обмен

`exchange.wasm` — обычный вычислитель b^e mod p (p = 0x7bf45333234d47dd18d1823272bd2085, g = 2).
Для показателей длиной >108 бит `run` пишет в trace-буфер 8 байт, где
word = старшие 20 бит показателя, упакованные «полубайтовыми» перестановками:
`n0 = word>>24, n1 = word>>16, n2 = word>>8` → `top20 = (n2<<16)|(n1_hi<<12)|(n1_lo<<8)|(n0_hi<<4)|n0_lo`.
Верхние 20 бит не нужны для решения: p−1 = M·Q, где

* M = 2^2·3^3·5^2·7·11·…·53 (72 бита, гладкое),
* Q = 56175345525792329 (простое, ~2^56).

Pohlig–Hellman по M (перебор маленьких подгрупп) + Pollard rho в подгруппе порядка Q
(`solve/pollard_rho.c`, Монтгомери-арифметика 128 бит) дают показатель целиком.

```
cd solve
gcc -O3 -march=native -o rho pollard_rho.c -lpthread
python3 exchange_solve.py     # -> K = 2e918f1abbdd662d6884b8d22cf3cb61
```
K — ключ XOR (повторяется 16-байтовым блоком). Расшифровка ciphertext:
`flag{lagged_limb_9d2f31}`.

## 2. «Секста»

Каждый поворот лимба — аффинное отображение r ↦ A·r + b над F_251 (линейная часть
нижне-/верхнетреугольная, проверено). Композиция двух вахт — тоже аффинное
отображение. Поэтому:

1. По 16 испытаниям (по 6 известных каналов) восстанавливаются 8 строк выходных
   каналов (8x8 + смещение) как решение линейных систем — `sexta_prep.py`.
2. Первая вахта: перебираются все 8^7 последовательностей индексов (для обеих
   таблиц, порядок вахт неизвестен); фильтр — «печать» (сумма после первой вахты
   для эталонного старта = 112).
3. Для каждого кандидата середины решаются строки второй вахты; мультимножество
   строк (8x9) хешируется и ищется в предвычисленной таблице всех 2·8^7
   последовательностей второй вахты. Совпадение хеша + проверка перестановки каналов
   w и всех испытаний даёт уникального кандидата:
   order=1 (утро→ночь), первая вахта 1134862, вторая 1332613,
   w = (0,7,2,6,1,4,3,5).

```
gcc -O3 -o sexta solve/sexta_solver.c
python3 sexta_prep.py     # пишет blob2.bin
./sexta                 # пишет cands.txt (уникальный CAND)
python3 sexta_decrypt.py  # сборка ключа SHA-256 и AES-256-GCM
```
`flag{unaligned_watch_81d4}`

## Файлы

* `exchange_solve.py` — DLP и дешифровка XOR.
* `pollard_rho.c`, `core.h` — rho для подгруппы порядка Q.
* `sexta_prep.py` — восстановление отображения каналов, подготовка блоба.
* `sexta_solver.c` — meet-in-the-middle по вахтам.
* `sexta_decrypt.py` — проверка наблюдений, trace и AES-256-GCM.
