# Physics Clicker — запуск и обход проверки

## Что выяснено точно

1. **`steam_api64.dll` обязательна.** Без неё Windows выдаёт «Не удается продолжить выполнение кода,
   поскольку система не обнаружила steam_api64.dll» — это статический импорт, `PC.exe` не стартует вообще.
   Удалять dll нельзя.
2. **Оригинальная dll обязательна, а не патченная на экспортах.** `PC.exe` не импортирует ни одного
   `SteamAPI_ISteamApps_*` — только `SteamInternal_FindOrCreateUserInterface` и
   `SteamInternal_SteamAPI_Init`. Значит игра получает интерфейс `STEAMAPPS_INTERFACE_VERSION009`
   и вызывает `BIsSubscribedApp` через vtable. Заглушки на экспортах недостижимы — поэтому
   пропатченный файл из `steam_api64_patched.dll` приводит к мгновенному закрытию.
3. **Игра на Lua.** `core.src` и `main.src` — ZIP-архивы (162 и 193 файла), внутри `Core/` и `Main/`.
   Все `.lua` зашифрованы **AES (ZIP method 99)**. Видно дерево, размеры и имена, но не код.
   Ключ зашит в `PC.exe` (это LuaSTG-подобный движок со встроенным `lstg.Archive`).
4. **Модуль Steam есть в ядре:** `Core/Steam/init.lua` (6754 байта). Именно там проверка.
   Рядом `Main/Achievement/ToSteam.lua` — достижения в Steam.

## Что делать

`game/` — папка с **оригинальной** dll, готова к запуску.

Но для обхода нужен **эмулятор Steam**, который грузит настоящий `steam_api64.dll`
и подменяет реализацию интерфейсов изнутри (vtable), а не заглушками на экспортах:

```
https://github.com/Detanup01/gbe_fork/releases/latest
→ emu-win-release-vs22.7z
```

Порядок:
1. Распаковать архив, найти `steam_api64.dll` для x64.
2. Положить её в `game/` **вместо** оригинальной (оригинал сохрани в `steam_api64.dll.orig`).
3. Положить рядом `steam_appid.txt` с любым числом (эмулятор подставит свой).
4. Запускать `PC.exe` напрямую, Steam-клиент не нужен.

Почему это сработает там, где не сработал мой патч: эмулятор реализует весь интерфейс
`ISteamApps` целиком, включая vtable, и `BIsSubscribedApp` внутри возвращает «куплено».

## Если эмулятор недоступен

Тогда путь через AES-ключ от `.src`:
1. Найти в `PC.exe` ключ (ищи вызовы `BCryptImportKey` / `BCryptEncrypt` рядом с разбором ZIP —
   движок импортирует `bcrypt.dll`).
2. Расшифровать `core.src` → `Core/Steam/init.lua`.
3. Там будет либо вызов `BIsSubscribedApp`, либо собственный онлайн-чек лицензии.
4. Подменить архив на распакованный и запустить.

Но это дольше; эмулятор решает ту же задачу за минуту.

## Осторожно про «лицензию»

Если после эмулятора игра всё равно требует ключ — значит проверка **своя, не Steam-овая**
(сервер автора). Тогда её надо искать в `Core/Steam/init.lua` после расшифровки.
